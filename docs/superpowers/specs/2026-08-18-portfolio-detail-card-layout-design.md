# Portfolio Detail Card Layout

## Goal

Replace the portfolio card detail sheets' horizontally scrollable tables with responsive stacked position cards.

## Design

- Open detail keeps pool header and adds summary PnL/balance/fees, followed by one card per live position.
- Each open position card shows address/link/copy, price range, age, token amounts, token fees, and PnL where available.
- Closed detail shows one card per closed position with address, deposit, withdrawal, fees, PnL USD/SOL with percentages, and close time.
- The main portfolio table and inline desktop expansion remain unchanged.
- Sheet content uses normal vertical scrolling only.
